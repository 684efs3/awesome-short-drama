# Contributing to Awesome Short Drama

Thank you for your interest in contributing!

## Guidelines

- Make sure the resource you're adding is related to short dramas / micro-dramas.
- Add new entries in alphabetical order within their section.
- Use the format: `[Name](URL) - Brief description.`
- Check that your link is working before submitting.
- One pull request per resource addition.

## Adding a New Resource

1. Fork this repository.
2. Add your resource to the appropriate section in `README.md`.
3. Submit a pull request with a brief description of why this resource is awesome.

## Quality Standards

- The resource should be actively maintained.
- No spam, affiliate links, or low-quality content.
- Resources should provide genuine value to the short drama community.
